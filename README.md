## 2. 제품 한 줄 요약

만 8~9세 아동의 **금융 행동 실천을 기록하고 그 변화를 보호자에게 증거로 제시하는** 폐쇄형 선불카드 기반 금융교육 플랫폼.

- **선언 ①** — 자녀가 금융을 학습하고 **금융 행동을 실천하며 성장**한다 *(아이 · 실천 계층)*
- **선언 ②** — 얼마나 배웠는지가 아니라 **금융 행동이 어떻게 달라졌는지**를 한 눈에 보여준다 *(보호자 · 증거 계층)*

선언 ①이 선언 ②의 전제다. 북극성 KPI는 **WPA(주간 실천 인정 아동 비율)** 하나다.

## 3. SRS 문서 구성

SRS는 **1~7장을 사내 SRS 표준 양식**에 맞춰 작성하고, PRD에는 있으나 그 양식에 대응 절이 없는 내용을 **ISO/IEC/IEEE 29148:2018 §9.6**에 따라 **8~12장으로 확장**했다.

| 장 | 내용 | 구분 |
|:-:|---|---|
| 1 | 서론 (목적 · 범위 · 정의) | 표준 양식 |
| 2 | 이해관계자 | 표준 양식 |
| 3 | 시스템 맥락 및 인터페이스 | 표준 양식 |
| 4 | 구체적 요구사항 — 기능 18 · 비기능 24 · **규제 9** | 표준 양식 + 4.3 확장 |
| 5 | 추적성 매트릭스 | 표준 양식 |
| 6 | 부록 — API · 데이터 모델 · 비즈니스 규칙 · DB 스키마 · **이벤트 명세** · **모니터링 SLA** | 표준 양식 + 6.5·6.6 확장 |
| 7 | 향후 개선 사항 | 표준 양식 |
| **8** | **성과 측정 요구사항** (북극성 KPI · MOE 15종) | 확장 — 29148 §6.3.3.3 · §6.6.3 |
| **9** | **사용자 스토리 및 인수 기준** (스토리 8 · AC 50) | 확장 — 29148 §9.6.5 · §9.6.6 |
| **10** | **가정 · 의존성 · 제약 · 리스크** (리스크 9) | 확장 — 29148 §9.6.8 · §9.6.7 · §5.2.8 |
| **11** | **설계 결정 근거 (ADR 8건)** | 확장 — 29148 §5.2.8 · §9.6.16 |
| **12** | **검증 및 확인 (V&V)** — 실험 11 · 스프린트 배분 · 롤아웃 게이트 | 확장 — 29148 §9.6.19 · §6.5.3 · §9.6.9 |

## 4. 저장소 관리 규칙

- **최종 산출물만 올린다.** 참고 문서(표준 원문 · 타 제품 SRS 예시)와 이전 판본은 저장소에 포함하지 않는다
- 두 문서는 **서로 참조**한다 — SRS 요구사항표의 「출처」 열이 PRD 절 번호를 가리킨다. 한쪽을 고치면 다른 쪽의 참조를 함께 확인한다
