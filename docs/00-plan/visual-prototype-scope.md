# [경량 시각 프로토타입 범위] Node 없이 지금 할 수 있는 것

- **문서 ID:** PROTO-LIGHT-FINFRIENDS-001
- **버전:** 1.0
- **작성일:** 2026-08-27
- **상위 문서:** [`prototype-suggestion.md`](prototype-suggestion.md) — 본 문서는 그 14건을 **4건으로 한 차례 더 추린 것**이다
- **성격:** 실행 지시서. 승인 즉시 착수 가능하며 **선행 조건이 없다.**

---

## 1. 왜 한 번 더 추리는가

상위 문서의 P0 실행 계획(9화면 · 2.5 MD)은 **선행 조건 2건에 막혀 있다** — `prototype-suggestion.md` §7.

| 차단 | 내용 |
|:--:|---|
| **R-P7** | 로컬에 `node`·`npm`·`npx`·`pnpm`·`yarn` **전부 없음.** `create-next-app`·shadcn init·`npm run build` 불가 |
| **R-P1** | 화면을 만드는 태스크가 DAG에 없음. 티켓화 여부 미결 |

두 조건이 풀리기를 기다리는 동안 **시각 판단은 멈출 필요가 없다.** 색·타이포·여백·라운드 같은 시각 언어는
프레임워크와 무관하며, 지금 확정해두면 Node 설치 후 P0가 그대로 받아 쓴다.

> **핵심 전환** — 이 차수의 산출물은 화면이 아니라 **디자인 토큰**이다 (§5).
> HTML 목업은 토큰을 눈으로 판정하기 위한 수단이며 P0 착수 시 폐기한다.

---

## 2. 추림 기준

상위 문서의 Tier 1(9) + Tier 2(5) = **14건**에 아래를 적용한다.
**L1을 필수 전제**로 하고 L2~L4 중 **2개 이상**을 만족하면 채택한다.

| ID | 기준 | 판정 |
|:--:|---|---|
| **L1** | **빌드 무의존** *(필수)* | 브라우저로 `.html` 을 직접 열어 확인되는가. Node·번들러·패키지 설치가 필요하면 탈락 |
| **L2** | **정적 1장으로 성립** | 상태 전이·폼 제출 없이 **멈춘 화면 한 장**이 의미를 갖는가 |
| **L3** | **듀얼 테마 판별력** | Fun Mode 와 Clean Mode 의 시각 언어 차이를 **이 화면 하나로** 드러내는가 |
| **L4** | **토큰 수확량** | 이 화면을 그리면 색·타이포·여백·라운드 토큰이 **몇 개나 확정되는가** |

### 제외 기준

| ID | 기준 | 왜 이 차수에서 빼는가 |
|:--:|---|---|
| **XL1** | **가치가 전이에 있는 화면** | 정적 캡처로는 핵심을 못 본다. 여러 장을 그려야 하므로 "가볍게"에 반한다 |
| **XL2** | **코어 루프 밖** | 시각 판정의 우선순위가 낮다. 다음 차수로 미룬다 |
| **XL3** | **다른 화면에 흡수** | 독립 화면으로 세지 않고 채택 화면의 일부로 그린다 |

## 4. 산출물 형태 — 빌드 체인 없음

```
docs/00-plan/mockups/
├── README.md          # 열어보는 법 · 토큰 판정 체크리스트
├── tokens.css         # ★ 진짜 산출물 — 듀얼 테마 CSS 변수 (§5)
├── child-tree.html    # 1번
├── parent-forest.html # 2번
├── child-retro.html   # 3번 — 3상태를 한 페이지에 나란히
└── child-plan-new.html# 4번
```

- **각 `.html` 은 브라우저로 더블클릭해 연다.** 서버·설치·빌드 없음.
- 스타일은 전부 `tokens.css` 의 CSS 변수를 참조한다. **하드코딩한 색을 쓰지 않는다** — 그래야 토큰이 산출물이 된다.
- 애플리케이션 디렉토리(`app/`·`components/`)를 만들지 않는다. `AGENTS.md` §2가
  "버전 확정 전까지 임의 버전을 가정하고 코드를 쓰지 않는다"를 명시하며, 이 목업은 Next.js 코드가 아니다.
- 목업은 `docs/` 아래 계획 문서의 부속물이므로 `AGENTS.md` §3 애플리케이션 디렉토리 규약과 충돌하지 않는다.

## 5. 진짜 산출물 — 듀얼 테마 토큰

목업은 버려도 **아래 표가 확정되면 이 차수는 성공**이다. Node 설치 후 P0가 이 값을 그대로
`tailwind.config.ts` 와 `app/globals.css` 로 옮긴다.

| 토큰 축 | Fun Mode (아동) | Clean Mode (보호자) | 근거 |
|---|---|---|---|
| **역할** | 재미·즉각 보상·성장 실감 | 증거 제시·판단 지원 | SRS §2.1 2대 가치 |
| **정보 밀도** | 한 화면 1주제 | 한 화면 7지표 | REQ-FUNC-005 vs 009 |
| **채도** | 높음 — 원색 계열 | 낮음 — 뉴트럴 + 액센트 1 | SRS §0 "Fun/Interactive" vs "Clean" |
| **본문 크기** | 크게 | 표준 | 만 8~9세 가독성 |
| **모서리 라운드** | 큼 | 작음 | — |
| **여백** | 넉넉 | 조밀 | 정보 밀도의 귀결 |
| **모션** | 스케일·바운스 (별 지급) | 페이드만 | — |
| **주 시각 요소** | 일러스트 (나무·아바타·별) | 데이터 (표·게이지·증감) | — |
| **문구 톤** | 아동용 언어 | 보호자용 언어 | `AGENTS.md` §5 에러 처리 |

> 구체 수치(hex·px·ms)는 목업을 그리면서 채우고 `tokens.css` 가 SSOT가 된다.
> 본 표는 **값이 아니라 축과 방향**을 고정한다.

### 이 차수에서 답해야 할 질문 4개

1. 두 모드를 나란히 놓았을 때 **한눈에 다른 서비스로 보이는가** — 너무 달라도 실패다
2. 아동 화면에서 **별이 가장 먼저 눈에 들어오는가** (별은 핵심 시각 언어다)
3. 보호자 화면의 7대 지표가 **스크롤 없이 한 화면에 들어오는가**
4. 회고 3상태가 **문구를 읽지 않고도 구별되는가** (칭찬 / 격려 / Fallback)

## 7. 범위 밖 — 이 차수에서 하지 않는 것

- **Next.js·React·Tailwind·shadcn 설치나 설정** — Node 부재. 시도하지 않는다
- **`app/`·`components/`·`package.json` 생성** — P0의 몫이며 `AGENTS.md` §2 위반
- **상태 전이·폼 제출·라우팅 동작** — 정적 HTML의 범위 밖
- **Server Action·DB·API 연결** — 이 차수는 전부 하드코딩 카피다
- **반응형 전 브레이크포인트 대응** — 모바일 폭 1종(390px 기준)만 본다
- **접근성 감사** — P0 이후 별도 차수

### 그래도 지켜야 하는 것 (면제 없음)

`AGENTS.md` §4 불변식은 목업에도 적용된다.

- `/child/plan/new` 에 **지도·"현재 위치" 버튼·주변 가맹점 UI 를 넣지 않는다** (REG-002)
- 아바타는 **그래픽만.** 사진 업로드 컨트롤 미배치 (REG-006)
- 별에 **"원화 환산"·"출금" 표기를 넣지 않는다** (REG-005c)
- 금지 식별자를 클래스명·변수명에 쓰지 않는다 — `latitude` `longitude` `geolocation` 등

## 8. 공수와 순서

| 순서 | 산출물 | 예상 | 완료 판정 |
|:--:|---|:--:|---|
| 1 | `tokens.css` 초안 + `child-tree.html` | 1.5h | 브라우저에서 열리고 Fun Mode 언어가 성립 |
| 2 | `parent-forest.html` | 1.5h | 1번과 나란히 놓아 §5 질문 1·3에 답이 나옴 |
| 3 | `child-retro.html` (3상태) | 1h | §5 질문 4에 답이 나옴 |
| 4 | `child-plan-new.html` | 0.5h | REG-002 준수 UX가 시각적으로 확정 |
| 5 | `tokens.css` 확정 + `mockups/README.md` | 0.5h | 하드코딩 색 0건, 토큰 표(§5) 전 축이 값을 가짐 |

**합계 약 5시간 (0.5 MD 이하).** 상위 문서 P0~P3(2.5 MD)의 **선행 투자**이며 중복이 아니다 —
P0 의 0.5 MD 짜리 "듀얼 테마 토큰 정의"를 이 차수가 대신 끝내기 때문이다.

> 이 차수가 끝나면 Node 설치 여부와 무관하게 **시각 방향이 확정된 상태**가 된다.
> P0 는 확정된 토큰을 Tailwind 로 옮기고 나머지 5화면을 추가하는 일만 남는다.
